## Selected work

**Preschool handwriting practice app**  
A mobile application for children aged 3–6 to practice lines, shapes and letter tracing. Developed drawing interactions with Flutter's `CustomPainter`, tracked drawing performance metrics and integrated voice assistance (STT/TTS). Backend services use FastAPI and PostgreSQL.

**University club and event management system**  
A role-based web application for managing university clubs, memberships and event approval workflows. Built with React, Flask and PostgreSQL, with different interfaces and permissions for students, club officers, advisors and administrators.

**AI-assisted open-ended exam system**  
An application for creating exams from uploaded PowerPoint files. It supports teacher and student workflows, exam assignment and AI-assisted question generation through the OpenAI API.
