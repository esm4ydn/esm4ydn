<summary><b>Selected projects · Read more</b></summary>

<br/>

### Preschool handwriting practice app

A mobile application for children aged 3–6 to practice lines, shapes and letter tracing. I worked on drawing interactions using Flutter `CustomPainter`, drawing-performance metrics, and voice assistance (STT/TTS). The backend uses FastAPI and PostgreSQL.

### University club and event management system

A role-based web application for university clubs, memberships and event approvals. Built with React, Flask and PostgreSQL, with interfaces and permissions for students, club officers, advisors and administrators.

### AI-assisted open-ended exam system

A tool for generating exam questions from uploaded PowerPoint files using the OpenAI API. Includes teacher and student workflows, document uploads and exam assignment.
